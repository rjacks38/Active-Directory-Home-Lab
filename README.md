# Active Directory & Domain Controller Home Lab

## Project Overview
Created and designed a functional and secure Active Directory network environment to practice with **user management, domain configurations, and security logging**. 

In this lab, I learned how to deploy a domain where users are secure, including the configuration of isolated virtual networking components such as **NAT networks and Internal networks**. Toward the end, I went through hands-on troubleshooting and successfully resolved technical issues throughout the process of provisioning and joining my client computer in VirtualBox.
